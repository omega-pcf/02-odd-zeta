# Witness decisions — one row per question

The family's decision ledger. **One row per question; a count is never a row.**
`resolution` states what was decided or what is still owed; `ref` names the
document and section that carries the evidence — and, where a figure is
invoked, the document that carries the figure itself. Rows are added when a
question is surfaced — a rule already decided here is never re-surfaced in a
brief. Measured figures are dated and re-measured before reuse. Standard: see
`docs/witness-contract.md` §6.
